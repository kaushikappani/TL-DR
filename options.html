MCP tools

Connect MCP servers that speak the Streamable HTTP transport. Their tools are handed to the model while you chat about a page, and it calls them when a question needs one.

The chat shows which tool the model wants and why; nothing runs until you press Run. Turn this off to let approved servers run unattended.

A ceiling on the tool loop so a single question can't run away.

Quick actions

After each summary the model reads what the page actually is — a receipt, an invite, a booking — and offers a couple of one-tap follow-ups written for it. Ones marked 🔧 run a connected tool, and tapping the chip is the approval, so they run without a second prompt. Costs one small extra request per summary.

Only add servers you trust. The model chooses the arguments it sends, and those can include text from the page you're reading. Auth headers are stored in your browser's synced extension storage, the same place as your API keys.
